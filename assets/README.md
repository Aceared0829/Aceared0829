## Banner

`ninghong-banner.png` is original concept artwork for the NingHong GitHub profile. It is not a project screenshot or evidence of a completed implementation.

Created with the built-in image generation tool on 2026-09-08. The generated PNG is preserved without image edits.

Prompt:

> Use case: stylized-concept. Asset type: a polished panoramic bitmap banner for NingHong's GitHub developer profile, approximately 3:1 aspect ratio, suitable for displaying at 900px wide. Create a sophisticated editorial technical illustration for an Unreal Engine / C++ developer working on gameplay, engine systems, character animation and scripting tools. Full-bleed nearly-black graphite background, clean soft-white oversized typeset title 'NingHong' centered across the main field, with small clear subtitle 'GAMEPLAY / ENGINE / MOTION' under it. The typography is the primary focus, bold modern grotesk, straight baselines, exact correct spelling, not pixel art. Around the margins, a restrained isometric study of articulated motion joints and modular component blocks, rendered as crisp tactile 3D objects and fine technical trajectory lines, with mint-green and one small coral-red accent. The illustration should feel like a carefully art-directed engineering sketchbook, spacious and balanced, not a gaming streamer banner and not a futuristic HUD. A small tasteful coordinate diagram is okay, no extra readable words or random labels. Keep all essential text well away from edges and easily legible when reduced. This is original profile artwork, not a screenshot or claimed result of any project. No logos from Unreal or other companies, no fake code, no stock photographs, no gradient orbs, no bokeh, no rounded decorative cards, no purple/blue neon, no watermark.
